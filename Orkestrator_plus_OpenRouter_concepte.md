# Впровадження оркестратора й підключення моделей LLM через коннектор OpenRouter
1) Потрібно створити orchestrator.js на Node.js в якості оркестратора системи який буде виконувати точку входу INSTRUCTIONS.md
2) Для рою агентів різних ролей системи потрібно підключити OpenRouter
3) потрібно  в .env які моделі будуть підключатися із OpenRouter. Потрібно твоя думка як краще визначати які моделі будуть використовуватися для окремих ролей. Можливо краще відразу в env прописувати визначення підключення й використання моделей LLM із OpenRouter для ролей? 
4) Потрібно при запуску оркестратора веріфікувати визначення й доступність моделей LLM для вісх ролей.Якщо для однієї з ролей не буде або прописана модель або ця визначена модель не буде доступною, то потрібно аварійно з друком у лог заверхувати роботу оркестратора
